# Netflix Movies and TV Shows Clustering

This repository contains a data science project focused on clustering Netflix titles using Machine Learning techniques.

## Project Structure
- `netflix_titles.csv`: Dataset containing details of movies and TV shows available on Netflix.
- `netflixcode.ipynb`: Jupyter Notebook containing data preprocessing, exploratory data analysis (EDA), and clustering model creation.
- `netflix_clustering_model.pkl`: Serialized clustering model.
- `appNet.py`: Python script for running the application.

## Requirements
To run this project locally, install the required dependencies:
bash
streamlit run appNet.py

## Usage
Run the web application using:
bash
streamlit run appNet.py
